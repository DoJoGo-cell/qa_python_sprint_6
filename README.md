# qa_python_6 - Тестирование сервиса Яндекс Самокат

Автоматизированные тесты для сайта [Яндекс Самокат](https://qa-scooter.praktikum-services.ru/).
Проект проверяет следующие функциональности:
- Выпадающий список вопросов в разделе "Вопросы о важном"
- Заказ самоката
- Переходы между страницами по логотипам

## Реализованные тесты (12 тестов):

### 1-8. Тесты выпадающего списка вопросов (8 вопросов)
- `test_question_and_answer` — проверка появления соотвествующих ответов при нажатии на вопросы в разделе Вопросы о важном

### 9-10. Тесты заказа самоката
- `test_ordering_by_clicking_button_above` — проверка полного пути заказа самоката при нажатии на Верхнюю кнопку оформления заказа на главной странице сервиса
- `test_ordering_by_clicking_button_below` — проверка полного пути заказа самоката при нажатии на Нижнюю кнопку оформления заказа на главной странице сервиса

### 11-12. Тесты переходов между страницами по логотипам
- `test_transition_to_main_page` — проверка перехода на главную страницу Яндекс Самокат нажатием на Логотип "Самокат" на странице оформления заказа
- `test_transition_to_dzen_page` — проверка перехода на страницу Яндекс Дзен нажатием на Логотип "Яндекс" на главной странице сервиса

## Установить зависимости
pip install -r requirements.txt

## Запуск тестов
pytest -v tests/
